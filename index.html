☁️ تنظیمات ذخیره ابری

          
        

        

          

            با GitHub Gist دیتات رو بین گوشی/لپ‌تاپ همگام کن.

            Token فقط در همین مرورگر ذخیره می‌شود؛ این دستگاه باید شخصی و امن باشد.

            🔗 ساخت Token
             • 
            🔗 ساخت Gist
          

          

            
            
            

              از
              github.com/settings/tokens
              بگیر (فقط scope "gist" کافیه)
            

          

          

            
            
            

              یه Secret Gist بساز با محتوای {"init":true}، بعد ID
              رو از URL کپی کن
            

          

          
          
          
اگر خاموش باشد، Token فقط تا بسته‌شدن مرورگر در session نگه‌داری می‌شود.

          

          

          

            
🛡️ مرکز ایمنی و بازیابی

            
قبل از اولین تغییر، یک snapshot تغییرناپذیر از Gist فعلی و یک کپی از دیتای محلی ساخته می‌شود.

            پروژه‌ت چیه.
          


          

            
            
          

          

            
            
          

          

            
            
          

          

            
            
          


          
          

          

            

              
              
            

          


          


          

            
            
            
            
          


          


          


          

            💡 راهنما:

            1. نوع درخواست رو انتخاب کن

            2. اگه توضیح خاصی داری، بنویس

            3. کلیک "⚡ تولید متن"

            4. کلیک "📋 کپی"

            5. برو تو ChatGPT/Claude/Gemini، paste کن

            6. AI کاملاً می‌فهمه و کمکت می‌کنه!
